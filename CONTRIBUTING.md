# Contributing

Issues and pull requests are welcome.

1. Fork the repository and create a focused branch.
2. Keep components dependency-light and prefix public CSS classes with `aui-`.
3. Run `npm run check` and `npm run build`.
4. Describe behavior, accessibility, and visual changes in the pull request.

Only submit code and assets you have the right to license under MIT. Do not copy proprietary component libraries or brand assets into this repository.
